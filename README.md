# AIPromptPro - 500 Powerful AI Prompts Collection

A premium, high-converting landing page for a digital product offering 500+ hand-crafted AI prompts for creators and professionals.

## 🚀 Features
- **Modern UI**: Dark-themed, premium aesthetic with glassmorphism and smooth animations.
- **Interactive AI Terminal**: Simulated AI assistant typing effect to demonstrate product value.
- **Testimonial Slider**: Fully responsive slider showcasing verified customer reviews.
- **Mobile Optimized**: Seamless experience across all devices with touch-friendly elements.
- **Fast Loading**: Built with pure HTML, CSS, and Vanilla JS—no heavy frameworks or image dependencies.

## 🛠️ Deployment
This project is designed for static hosting on **GitHub Pages**.

### Steps to Deploy:
1. Push the code to your GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, ensure the source is set to `Deploy from a branch` and the branch is `main`.
4. (Optional) Configure your custom domain in the **Custom domain** field.
